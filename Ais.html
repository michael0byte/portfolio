Dynamic Combat AI

This AI system features dynamic decision making based on health and proximity, utilizing Selectors and Decorators to fluidly switch between three primary states: Chase, Attack, and Flee.

Logic Flow :

  • Flee State (Survival)
    The primary check is health-based. The IsHealthLess25_Dec Decorator is set to Low Priority Abort. If the AI's health drops below 25% at any point during combat, it immediately aborts current actions and enters the Flee state. It calculates a random reachable point far from the player, runs there, heals itself over time using a Timer, and then resumes combat once fully recovered.
    •  
  • Decision Node: Combat vs. Chase
    If health is stable (>25%), the logic falls back to a secondary Selector. This branch uses the IsPlayerNear_Dec Decorator to evaluate the distance to the target player.
    •  
  • Chase State
    If the player is outside the attack range, the AI executes a standard Move To task, navigating the environment to close the distance to the player.
    •  
  • Attack State
    Once within range, the Player Near Sequence is executed. The AI focuses on the player (adjusting Yaw), executes the HitPlayer Task (playing the attack montage), unfocuses to allow free movement, and waits for a brief cooldown period before assessing the next move.
